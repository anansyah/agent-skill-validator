Agent Skill Validator

Auto-test AI agent skills for broken dependencies, compatibility issues, and security risks.

Python 3.9+ MIT Beta
View on GitHub

Quick Start

pip install agent-skill-validator
agent-skill-validator validate ./my-skill-repo
agent-skill-validator report ./my-skill-repo --output report.md

Features

Dependency Health
Missing imports, broken manifests, unpinned versions.
Security
Hardcoded secrets, unsafe shell commands, placeholder keys.
Compatibility
Deprecated model references, context-length blind spots.
Format
Missing frontmatter, broken markdown links.
